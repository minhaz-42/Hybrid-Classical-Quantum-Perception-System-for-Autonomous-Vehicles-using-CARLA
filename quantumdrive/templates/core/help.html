❓ Frequently Asked Questions

How do I start a simulation?
Navigate to the Simulation page from the sidebar. Click "Start Simulation". The system will initialise a virtual CARLA session, begin generating vehicle state data, and start the decision loop. You can monitor real-time telemetry on the Dashboard.
What is the difference between Classical and Quantum decisions?
Classical decisions use a rule-based engine that evaluates lane occupancy, obstacle distance, and traffic-sign priority using if-else logic and weighted scoring.

Quantum decisions run the same feature set through a 4-qubit Variational Quantum Classifier (VQC) with angle-encoded inputs and entanglement layers. The VQC outputs a probability distribution over five actions (maintain, turn-left, turn-right, slow-down, emergency-stop), adding noise-resilient pattern recognition.
How do weather changes affect driving decisions?
Weather presets modify visual noise, surface friction, and sensor reliability inside the perception pipeline. For example:
  • Heavy Rain — reduced lane visibility, increased stopping distance
  • Dense Fog — limited perception range, higher decoherence noise
  • Sandstorm — extreme noise on all channels
The quantum layer applies adaptive noise parameters per weather mode, while the classical engine applies static discount factors.
Can I export simulation data?
Yes. Go to Model Comparison or Settings → Data Management and click "Export All Data (CSV)". This downloads every decision log entry for the current session as a comma-separated values file compatible with Excel, Pandas, or any data tool.
What do the accuracy and confidence scores mean?
Confidence is the maximum probability output from either the rule-based scorer (classical) or the VQC softmax (quantum). A confidence of 0.92 means the model assigned 92 % probability to its chosen action.

Accuracy on the Analytics page is a simulated metric comparing model decisions to a baseline "ground-truth" controller within CARLA. It aggregates over the session history and is useful for comparative studies.
What are the system requirements?
  • Python 3.10+
  • Django 5.x & Django REST Framework
  • PennyLane (for quantum simulation)
  • CARLA 0.9.14+ (optional — the platform runs a simulated backend when CARLA is unavailable)
  • A modern browser (Chromium-based recommended)
